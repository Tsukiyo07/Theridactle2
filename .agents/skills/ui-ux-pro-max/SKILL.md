# UI/UX Pro Max Design Guidelines

## Fundamental Principles

1. **Zero Emojis in Professional UI**:
   - Use clean geometric SVG vector icons with 2px stroke width (Lucide / Tabler standards).
2. **Glassmorphic Material Contrast**:
   - Ensure dark mode translucent surfaces maintain WCAG 4.5:1 text contrast.
   - Use specular highlights (\inset 0 1px 0 rgba(255, 255, 255, 0.1)\) instead of diffuse blurry shadows.
3. **Proportional Radii**:
   - Small controls: 8-10px
   - Cards & panels: 14-18px
   - Pills (9999px): Strictly for buttons, tags, and inputs.
