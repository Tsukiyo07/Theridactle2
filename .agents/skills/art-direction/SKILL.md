# Awwwards-Level Art Direction & Creative Direction Skill

## 1. Core Philosophy: The Anti-Slop Aesthetic Enforcement
- **Eliminate Symmetrical Boredom**: Use intentional asymmetrical tension, diagonal visual flow, overlapping surfaces, and dynamic spatial rhythm.
- **No Random Floating Blobs**: Replace aimless floating circles with intentional radial ambient lighting meshes, spotlights, and directional glowing border beams.
- **Zero Generic Typefaces**: Reject Inter, Roboto, Arial, and system defaults. Pair distinctive display typefaces with high-contrast, razor-sharp monospace data tokens.

## 2. Defined Artistic Philosophy: "Luxury Cyber-Arcade / Editorial Dark"
- **Surface Materiality**: Obsidian dark foundation (#07090e), layered frosted glass (backdrop-filter: blur(24px) saturate(180%)), and 1px specular highlight rims (inset 0 1px 0 rgba(255, 255, 255, 0.12)).
- **Physical Texture**: Analog micro-grain noise overlay (2.5% - 3.5% opacity) to give physical weight to digital screens.
- **Lighting Physics**: Targeted spotlight hovers, chromatic glow accents, and responsive edge refraction.

## 3. Design Tokens Architecture
- **Spacing Grid**: Strict 4px/8px baseline (8px, 12px, 16px, 24px, 32px, 48px, 64px).
- **Typography Scale**:
  - Display: Outfit 800/900 (letter-spacing: -0.03em, line-height 1.1)
  - Data / Tokens: JetBrains Mono 700 (letter-spacing: 0.06em, uppercase)
  - Body / Reading: Plus Jakarta Sans 400/500/600 (line-height: 1.6)
- **Semantic Palette Matrix**:
  - Theridactle: Emerald #10b981 / Mint #34d399
  - Pokédactle / PokéCries: Electric Amber #f59e0b / Solar Gold #fbbf24
  - Merrydactle / Loup-Garou: Grand Line Crimson #ef4444 / Blood Moon #dc2626
  - Quiz Géographie: Oceanic Cyan #00f2fe / Deep Teal #06b6d4
  - L'Imposteur / Songless: Classified Magenta #ec4899 / Ultraviolet #a855f7

## 4. Agency-Grade Component Assembly (21st.dev / Magic UI Standards)
1. **Interactive Spotlight Cards**: Radial gradient glow tracking cursor or anchored to top-right with soft boundary dissipation.
2. **Glowing Border Beams**: Thin animated or gradient-lit borders with specular corner highlights.
3. **Tactile Micro-Feedback**: Physical instantaneous compression (:active { transform: scale(0.97); }) under 100ms.
4. **Staggered Orchestration**: Entrances powered by Anime.js with cubic-bezier(0.23, 1, 0.32, 1) easing.
